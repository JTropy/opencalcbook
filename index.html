语法与快捷键
快捷键
Enter（公式输入框内）在下方插入同级行
Tab / Shift+Tab在单元格间移动
↑ ↓上下移动选中行
Ctrl+S保存工程
Ctrl+Enter在公式编辑器中保存
F2打开当前行的公式编辑器
Delete删除当前行（含子行）
数据格式
工程文件是普通 JSON，扩展名 .ocb.json，可以直接用文本编辑器打开、用 Git 做版本管理。 所有数据都在本地，不上传任何服务器。
关于
OpenCalcBook 是一个独立实现的工程量计算书工具，MIT 协议开源。 与任何商业软件无关，使用自己的开放数据格式。
